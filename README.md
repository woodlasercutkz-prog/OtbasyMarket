# Otbasy Market (PWA)

Статичное PWA: `index.html`, `sw.js` (офлайн-кэш), `manifest.webmanifest`, `icons/`.
Языки: русский / қазақша. Оплата: Kaspi Gold (QR), заявки и 2FA через WhatsApp.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы в корень.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. Откройте `https://<логин>.github.io/<репозиторий>/` и нажмите «Установить» / «На экран Домой».

## Перед запуском
Номера продавца и разработчика и хеши их паролей заданы в `SEED.cfg` (`index.html`). Пароли меняются в кабинете.
Данные пока хранятся в браузере (localStorage); для общей базы нужен бэкенд (например, Supabase).
При изменении файлов поднимайте версию `V` в `sw.js`.

## Офлайн и облако
- Всё работает без интернета: данные хранятся на устройстве (IndexedDB + localStorage), приложение и иконки кэширует `sw.js`, библиотека QR лежит локально.
- Облако — Supabase. 1) Создайте проект, выполните `supabase.sql`. 2) В `index.html` впишите `CLOUD={url:'https://xxxx.supabase.co',key:'<anon key>'}`.
- Дальше синхронизация автоматическая: при появлении сети, раз в минуту и после каждого сохранения. Всё, что вводилось офлайн, отправляется в облако; при одновременной правке одной записи побеждает правка, сделанная на этом устройстве. Статус виден значком в шапке.
- Пароли в облако не отправляются (меняются отдельно на каждом устройстве). Политики в `supabase.sql` открытые (тестовый режим): ужесточите перед боевым запуском.

## Импорт из OtbasyCardSnap
Кабинет → Товары → «Импорт из CardSnap»: JSON-файл (массив или `{"products":[...]}`) с полями `name, cat, price, old, qty, rating, desc, specs, fest, img` (img — data:image). Импортированные товары сохраняются на устройстве и уходят в облако при наличии сети.
