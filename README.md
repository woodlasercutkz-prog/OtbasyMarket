# Интернет-магазин для дома (PWA)

Статичное PWA: `index.html`, `sw.js` (офлайн-кэш), `manifest.webmanifest`, `icons/`.
Языки: русский / қазақша. Оплата: Kaspi Gold (QR), заявки и 2FA через WhatsApp.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы в корень.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. Откройте `https://<логин>.github.io/<репозиторий>/` и нажмите «Установить» / «На экран Домой».

## Перед запуском
В `index.html` в объекте `SEED.cfg` замените демо-номера продавца и разработчика, а пароли
(по умолчанию `seller123` и `dev123`) сразу смените в кабинете.
Данные пока хранятся в браузере (localStorage); для общей базы нужен бэкенд (например, Supabase).
При изменении файлов поднимайте версию `V` в `sw.js`.
